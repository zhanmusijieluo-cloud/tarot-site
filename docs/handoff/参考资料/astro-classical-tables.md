# 古典技法数据表 (状态区Tabs: firdaria / 小限 / Aphesis / almuten / 阿拉伯点 / 恒星 / VOC)

实现: `StatusTabs.tsx`(UI) + `timing.ts`(主星表/法达/小限/Aphesis) + `fixed-stars.ts`(恒星) + `chart.ts`(arabicLots/cuspAlmuten/moonVoid + chartEvidence 三段). 位置: /astrology/chart 底部 Panel; tab 排顺序=宫神星同款.

## 通用布局约定 (6栏表/对齐/上色 — 爸爸逐项定标, 新表照此)
- 长表一律 6 栏横排 (单 table 内 6×n 列; 法达=主|次|起始日期, 小限=年|宫|主星): 条目按 rows[c*perCol+r] 填充, 每栏自上往下、栏间自左往右读; 栏间分割 = 每栏首列 `border-l border-dashed border-white/[0.12]` (第 1 栏不加).
- 度数+星座列对齐: 度数包 `<span className="inline-block w-[3.5em] text-right">` 右对齐, 星座符号 `ml-1.5` 钉固定位 — 度数长短参差会让符号飘 (爸爸点名「长度不一样，后面星座排列不一样」); 已统一 4 处 (黄道状态/宫位表/阿拉伯点/恒星表), 新表新增度数列照此.
- 「当前」行/段高亮: accent 背景 rgba(217,168,184,0.13) + 小字「当前」; 判定口径见各节 (法达/小限=curAgeExact, ZR=curDays); 与起点行色冲突时「当前」优先.

## 法达星限 Firdaria (Abu Ma'shar; 总 75 年; 段长集合唯一, 仅起点序不同)
- 日生: ☉10 → ♀8 → ☿13 → ☽9 → ♄11 → ♃12 → ♂7 → 北交3 → 南交2
- 夜生: ☽9 → ♄11 → ♃12 → ♂7 → 北交3 → 南交2 → ☉10 → ♀8 → ☿13
- 昼夜盘判定与引擎同口径 (太阳 7–12 宫=昼盘).
- 二级表 (宫神星同款六栏: 主|次|起始日期 ×6, 栏间虚线; 每栏自上往下、栏间自左往右读): firdariaTable() — 每主段平分 7 子段 (段长/7); 第 1 子段=主星自己, 之后按固定迦勒底循环序 ☉♀☿☽♄♃♂ 轮转 (独立于昼夜序); 交点段不细分 (一条, 次列=—); 75 年一轮, 表做 2 轮=150 年; 日期=出生日期+累计天数×365.2425 (真实年, 非 360 天岁).
- 参考截图首行日期=今天 ≠ 表从今天开始 — 那是该盘出生日恰为今天 (演示盘); 表永远锚定出生日期. 日期链可手算自检 (☉段第 1 条=出生日; ☿段第 4 条=出生+18 年+3×(13/7) 年 …).
- **「当前」高亮必须用含月日的精确年龄** curAgeExact=(now−出生日期)/365.2425yr: 整数岁 + 浮点边界会把标记卡在上一格 (31.25 岁须落在恰从 31 岁起的那格；用整数 31 会判给上一段末行). firdaria 用 curAgeExact 比较; 小限行高亮用 Math.floor(curAgeExact) 对行; ZR Aphesis 用 curDays (实际流逝天数, 其时间制本身按天).
- 大运起点行 (主=次, 或交点整段): 次列不重复符号 — 主格 `colSpan={2}` 合并主/次两格, 符号居中 (爸爸: 同大运同小运用一个符号展示, 好区分大运阶段); 整行按大运主星上色 — LORD_HEX in StatusTabs.tsx (☉#f0c470 ☽#c8d8f0 ☿#8fd8c0 ♀#e8a0b8 ♂#ff9c90 ♃#8cc0ff ♄#b8a8d0 ☊#d8c090 ☋#8898a8), 背景 ≈8% alpha (hex+`14`) + 日期文字同色.

## 小限法 Profections
- 0 岁=1 宫 (ASC 星座), 每年宫+1 星座+1; 年主星=年宫宫头星座庙主 (profections() 在 timing.ts).
- 显示=宫神星同款 6 栏表 年|宫|主星 (爸爸: 小限法也搞成这样): 自出生年起 101 年 (0–100 岁), 年列=出生年+age; 无星座列 (宫神星原版无); 当前行=Math.floor(curAgeExact) 对应行 accent 高亮.

## Aphesis / 黄道释放 (Zodiacal Releasing — L1+L2 完整, 宫神星同款, 与参考截图逐日期 100% 校准)
- 常量 ZR_VALUE (黄道序 白羊..双鱼) = [15,8,20,25,19,20,8,15,12,27,30,12]: 同一数值既是 L1 的「年」也是 L2 的「月」; 摩羯=27、水瓶=30 两座分开 (不可笼统按土星 30).
- 时间制: 一年=360 天, 一月=30 天 (≠ 法达的 365.2425 真实年!); 日期 = Date.UTC(出生年月日) + Math.round(累计天数)×86400000 (UTC 基准防时区漂移).
- L1: 自福点/精神点所在星座起黄道序, 每段 = ZR_VALUE×360d, 精确按理论天数截断 (不凑整到 L2 边界).
- L2: 每个 L1 内自 L1 星座起黄道序, 每子段 = ZR_VALUE×30d; 在 L1 末端截断 (所属 L1 的最后一条被切短).
- 解链 LB: 子段走满 **12 个** 之后 (不是「到达对宫即跳」— 初版假设经数据证伪), 第 13 个子段 = L1 星座的**对宫**, 此后从对宫继续黄道序; 每个 L1 至多一次 (剩余时长不够再走满一轮). 只有小年 >17.58yr (6330d) 的六座 ♊♍♋♌♑♒ 的 L1 会发生 LB, 短座走不到 12 个就被截断.
- 手册验证点: 射手 L1: 子段序 ♐360 ♑810 ♒900 ♓360 ♈450 ♉240 ♊600, ♋ 被截到 600d → L1 整 4320d; 摩羯 L1: 12 座走满 6330d → LB 跳 ♋ (LB@+6330d); 天秤 L1(2880d): ♎240 ♏450 ♐360 ♑810 ♒900 ♓360→被截到 120d, 短座走不满 12 无 LB; 与宫神星日期逐条吻合 (LB 标记落在跳转后第一行).
- 校准法 (方法论, 再遇对拍照用): 用 RapidOCR 把参考截图**全表日期**逐条读出 (符号 OCR 不可靠, 数字可靠) → 相邻日期求天数差 → 差值序列 (360/810/900/450/240… 全为 30 的倍数) 直接暴露 360天年+30天月制 → 试算到与截图日期 100% 吻合、LB 位置一致才收工. 参考软件「从今天开始」的表 = 该演示盘生日恰为今天, 表永远锚定出生日期.
- 福点/精神点两表各自独立对上过一张宫神星截图 (同一函数只换起点星座, 一表验证即双表): 射手起点福点表前段 8 行 + LB@2055-11-11 / 2082-06-22 全对; 天秤起点精神点表 16 行日期 + LB@2078-07-13 (♑→♋) / 2105-02-22 (♒→♌) 全对.
- UI: 6 栏 主|次|起始日期; 主/次列 = SignGlyph 矢量星座符号 (size 15); 段首行 (subSign===lordSign) colSpan=2 合并单符号 + 元素色 (signColor) 背景 hex+`14` (注意: ZR 段首用元素色, 法达起点行才用 LORD_HEX 行星色); LB 行日期后金褐 #cdb88a 小字「LB」; 当前段高亮 = curDays=(now−出生UTC)/86400000 落在 [startDays, 下一行 startDays) 的行, accent 背景优先; 跨度 100 年 (spanDays=100×360).
- 实现: zodiacalReleasing(lotSignIdx, by,bm,bd, spanYears=100) in timing.ts → rows{lordSign, subSign, y,m,d, lb?, startDays}; 旧 aphesisL1() 已无引用被取代 (函数暂留, 可删).

## 阿拉伯点 (六点 — 公式已用爸爸宫神星截图六点互验, 全部 ≤0.02°)
- 福点: 日 Asc+☽−☉ / 夜 Asc+☉−☽
- 精神点: 日 Asc+☉−☽ / 夜 Asc+☽−☉
- 物质点: Asc+♃−☿ (Firmicus, 不反转)
- 婚姻点男: Asc+♀−♄; 婚姻点女: Asc+♄−♀ (Dorotheus/Hermes, 不反转)
- 子女点: 日 Asc+♄−♃ / 夜 Asc+♃−♄ (Al-Biruni)
- 来源: skyscript.co.uk/alparts (Houlding) + augurine lot-of-substance. 方法论: 把用户参考截图当数值测试向量 — 六点同盘同时命中即体系证明.

## 月亮空亡 VOC
- 月出座(同星座)前不再与其余六政精确成主相位 (0/60/90/120/180) = 空亡.
- 实现: 月亮 0.05° 步长推进到座末, 其他星按其速度同步走; 任一主相位被穿越即非空亡. 展示: 特征面板判词行 + 证据文本.

## 黄道状态表列规格 (tab 1)
- 守护宫/曜升宫 = 该星作为庙主/曜升主所辖的宫头宫号列表 (遍历 cusps).
- 分数: 庙+5 曜升+4 三分+3 界+2 面+1, 失势−5 落陷−4; 0 分且游走 → '0 P'.
- 附属状态: 速度 (相对平均日行度 ±20% → 平均/快行/慢行), 得时/失时 (简化: 星派×盘×地平线上; 水星按半球; 轴不判), 东出/西入 (黄经落后太阳=东出; 太阳自身不标), 在日光下 (chart.underBeams), 逆行.

## 盘外圈信息带 (法达盘/小限盘 — outerBand, 仅经典线条盘)
- 爸爸定稿: 「法达盘」「小限盘」= 本命盘外圈挂信息环 (照「测测」参考图, 不是另起炉灶); 实现 = ChartWheel2D `outerBand='firdaria'|'profection'`, 经 ChartWheel 透传; 俯视/侧视忽略 (环只在经典线条盘); BandResult.tsx = 盘 + 环 + 摘要条 (当前大运/子段 或 当前年宫/主星), corner 资料卡+按钮堆照常.
- 几何: R_BAND_IN=395, R_BAND_OUT=444 (盘沿 R_OUT=392 之外); viewBox 920 半宽仅 460 — **年龄文字必放环带内缘 (R_BAND_IN+14≈409), 放外缘 (R_BAND_OUT+15) 会被 viewBox 裁掉**.
- 法达环: 12 点=0 岁, **顺时针**, 75 年=360° (角度=π/2−age/75·2π; 与盘 DIR 无关, 专用顺时针 arc helper); 段=大运, 直接由 `firdariaTable(dayChart,…)` 筛 `sub===lord || sub===null` 行取得 (单一数据源, 不另抄序表); 昼夜判定同状态区口径 (太阳 7–12 宫=昼盘); 段界标 `Math.round(m.startAge)` 岁 — 不对 startAge 取整会显示 "31.00000000000001岁" 浮点噪声; 段内等分画子段主星 glyph (7 个/段, 交点段 1 个, size≈13), 子段序=法达循环序以本段主星为起点轮转; 当前段 accent 淡底+文字变色高亮.
- 小限环: 每宫一段, 用**实际宫位跨度** (沿用扇区 sector() 跟随 DIR); 段内单字 = 宫头星座庙主星 (日/月/水/金/火/木/土); 当前年宫 = curAge%12+1 (curAge=floor((now−出生日期)/365.2425), 与 profections() 同式 — 改规则时两处同步) accent 高亮; **相邻段同字是普拉西德宫头挤宫的正常现象** (参考图同样连续「土土」), 不是 bug.
- 环带只做展示, 不参与行星选中; 与双环 (dualRing) 互不干扰.
